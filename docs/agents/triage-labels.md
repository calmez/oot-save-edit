# Triage labels

Map the skills' canonical triage roles to these GitHub label names:

| Role              | GitHub label      | Meaning                                  |
| ----------------- | ----------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue   |
| `needs-info`      | `needs-info`      | Waiting on the reporter for more details |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent   |
| `ready-for-human` | `ready-for-human` | Requires human implementation            |
| `wontfix`         | `wontfix`         | Will not be actioned                     |

When a skill names a triage role, use its label from this table. Edit the GitHub
label column if the repository's vocabulary changes.
